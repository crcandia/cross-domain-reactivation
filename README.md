# Cross-Domain Reactivation of Collective Attention in Music and Film

## Overview

This repository reproduces the analyses, tables, figures, and analysis-linked manuscript artifacts for the study linking Billboard Hot 100 song-artist records to Spotify popularity snapshots, Last.fm cumulative listener reach, IMDb soundtrack appearances, and movie metadata.

The authoritative workflow is the ordered set of executable Jupyter notebooks. The project is designed to be read, inspected, modified, and rerun interactively rather than driven by a project-wide wrapper script.

```text
preserved raw inputs
    -> 00 / 00b raw construction and checks
    -> 01 analytical panels and linkage
    -> 02 attention differences and matching
    -> 02b validated/rebuilt stochastic inference checkpoint
    -> 03 MemoryDecay and integrated temporal inference
    -> 04 embedding, visibility, and event-time analyses
    -> 05 artist-catalog and Last.fm analyses
    -> 06 validation and manuscript-artifact synchronization
```

Each notebook explicitly reads its required inputs, writes its own outputs, and can be opened and executed from a fresh kernel after the preceding notebooks have been run. No hidden in-memory state or final analytical master is used as a primary input.

## Repository structure

- `data/raw/` — preserved source-level and earliest-preserved study inputs, checksummed in `data/raw_checksums.csv`.
- `data/inference/` — validated replication-level rows for the expensive stochastic lower-pre-film inference: 500 pseudo-event assignments and 250 nested-bootstrap replications, plus hashes and support metadata.
- `data/expected_results.csv` — validation contract for support counts and headline results. It is not used to calculate estimates.
- `notebooks/` — authoritative analytical path, intended to be executed interactively in numeric order.
- `src/cdr/` — reusable mechanical implementations such as linkage construction, nonlinear fitting, matching engines, inference utilities, and table writers. Substantive analytical choices remain visible in the notebooks.
- `outputs/` — generated analytical datasets, result objects, figures, tables, diagnostics, and compiled analysis-linked PDFs.
- `manuscript/` — repository snapshot of manuscript sources and compile-time copies of generated figures/tables. Active manuscript drafting is maintained in Dropbox under `/Aplicaciones/Overleaf/Film-Linked Reactivation of Music in Collective Memory/`.

3. `notebooks/01_linkage_and_analytical_panels.ipynb`
4. `notebooks/02_attention_regimes_and_matching.ipynb`
5. `notebooks/02b_integrated_inference_checkpoint.ipynb`
6. `notebooks/03_memorydecay_and_dormant_reactivation.ipynb`
7. `notebooks/04_embedding_visibility_and_temporal.ipynb`
8. `notebooks/05_artist_catalog_and_lastfm.ipynb`
9. `notebooks/06_validation_and_manuscript.ipynb`

Notebook 02b contains one explicit execution choice for the expensive integrated stochastic inference:

```python
REGENERATE_INFERENCE = False
```

- `False` reuses the distributed replication-level rows only after validating their code hashes, input hashes, version, row counts, deterministic seeds, and raw-derived analytical-support fingerprint against the current project state.
- `True` regenerates all 500 pseudo-event assignments and 250 nested-bootstrap replications from the current analytical objects using the corrected primary MemoryDecay refit estimator, writes the new replication rows and metadata to `data/inference/`, and validates them before Notebook 03 is run.

Notebook 03 then independently validates the active replication files and recomputes every reported integrated-inference summary, interval, table, and figure from those rows.

This makes the computationally expensive step optional for exploration without allowing a stale or incompatible bootstrap to be silently reused.

All other analytical datasets, models, matching designs, tables, and figures are regenerated by their corresponding notebooks. Notebook 06 validates support counts, headline results, catalog results, visibility support, artifact identity, and LaTeX references, and refreshes the repository manuscript figure/table copies from `outputs/`.

## Data

The preserved inputs cover Billboard Hot 100 weekly charts, Spotify snapshots from October 2016, July 2017, August 2022, and August 2025, a July 2017 Last.fm snapshot, IMDb soundtrack/film linkage, and Box Office Mojo movie metadata. Legacy processed caches are retained for lineage checks where documented but are excluded from the primary runtime path.

The Box Office Mojo input is used as recorded in the preserved file. The current pipeline parses the recorded monetary strings and applies `log1p` in the film-visibility analysis; it does not apply an additional inflation or present-value adjustment. Exact acquisition metadata and redistribution status for the third-party box-office file are incomplete. Files listed in `data/public_exclude.txt` require redistribution review before public release.
